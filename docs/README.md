# Project documentation

This folder holds the current architecture and development context for Solution Studio. It replaces the former context documentation folder.

## Read in this order

1. [Architecture](ARCHITECTURE.md): folder ownership, dependencies, naming, and current implementation status.
2. [Design system](DESIGN_SYSTEM.md): planned text classes, component roles, styling ownership, and unresolved design values.
3. [Component inventory](COMPONENT_INVENTORY.md): exact scaffold filenames and their owners.
4. [Page map](PAGE_MAP.md): route files, design references, and reference ambiguities.
5. [Development guide](DEVELOPMENT_GUIDE.md): completed structural work and the future manual implementation sequence.

## Status and scope

This is a structure-only rebuild. The existing starter home page, root layout, global stylesheet, and application icons remain. All other source files are empty placeholders. A filename records intended ownership, not implemented behavior.

The PNG references are preserved. There is no editable Figma document in the reference folder. Responsive layouts, exact fonts, colors, spacing values, and interaction details still need review during implementation.

These documents do not claim working API handlers, persistence, validation, SEO output, accessibility compliance, or production readiness. No backend or deployment workflow has been added.
